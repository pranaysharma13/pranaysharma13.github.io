№ 03

Stock Movement Predictor

  • Tested whether 20 years of daily prices can predict tomorrow's direction and move size for SPY, NVIDIA, Apple and Google.
  • Compared logistic regression, gradient boosting and a PyTorch LSTM with year-by-year walk-forward tests from 2010 to 2026.
  • Found direction unpredictable, but the LSTM beat a strong volatility rule by 2.6–3.7 points on three stocks it hadn't seen.
  • Validated results with paired tests, Holm correction, luck checks and 184 automated tests, including leakage tests.
  • Built a live forward test on GitHub Actions that commits each day's predictions before the market opens.

№ 04

Python · NumPy · SciPy · Pandas

code ↗

Premier League 2026-27 Prediction Model

  • Built a Premier League 2026-27 prediction model from scratch in Python: a Dixon-Coles bivariate Poisson model fitted by weighted maximum likelihood, with a hand-derived analytic gradient checked against numerical differentiation.
  • Fitted the Premier League and Championship jointly, so promoted clubs get real priors. Added a mixed Poisson/Gamma likelihood that uses expected goals (xG) where available and actual goals elsewhere.
  • Ran a Monte Carlo season simulator (20,000 runs over 40 bootstrap refits) to produce title, top-4 and relegation odds and a finishing-position distribution for every club.
  • Validated it with walk-forward backtests scored by Ranked Probability Score against bookmaker closing odds. Fitting on xG beat goals-only in all three test seasons. Blending with the market gave a fitted weight of zero, and I published that result.
  • Found that season projections were overconfident (68.6% of clubs landed inside an 80% interval), tested two explanations that failed, and shipped a calibrated 1.5x widening that the site labels as an unexplained correction.
  • Shipped a static dashboard on GitHub Pages (vanilla JavaScript, SVG, Three.js): a finishing-position heatmap, points ranges, an in-browser fixture predictor, and the backtest and calibration evidence.

№ 05

Python · Streamlit · NetworkX · Matplotlib · Pandas

code ↗

DNA Sequence NFA Pattern Matcher

  • Built a DNA pattern matching engine from scratch that applies automata theory from CSE 355 to bioinformatics. It finds motifs like start codons (ATG), stop codons (TAA|TAG|TGA) and CpG islands in DNA sequences.
  • Implemented Thompson’s Construction with a recursive descent parser, converting patterns with wildcards, alternation, grouping, quantifiers and character classes into NFAs, with no automata libraries.
  • Wrote an ε-closure NFA simulator with leftmost-longest matching, plus subset construction to convert each NFA to an equivalent DFA and compare state counts against the 2ⁿ worst case.
  • Designed a 5-tab Streamlit dashboard with live NFA/DFA diagrams, transition tables, a step-by-step slider that shows multiple active states at once, and color-coded match highlighting.
  • Structured the code as a modular Python package, with the automata engine, visualization layer and UI in separate modules, so each concept in the theory maps to one file.
